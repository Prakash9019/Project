P0 / P1 — Fixed

Fixed Image moderation now defaults to manual review, not auto-publish

Flipped the default in backend/src/services/imageModeration.ts from allow to manual_review, and updated .env, .env.example, .env.test, and .env.prod to match. With no real Rekognition provider wired yet, every new upload now queues for human review instead of publishing uninspected — the API's existing pendingReview flag handles this without any other change.

Fixed Message-edit "Gold" gate now enforced server-side, in both 1:1 chat and Groups

Added a real plan check to both chat.service.ts and rooms.service.ts's editMessage, using the same isPaidPlan pattern already used for unsend. Verified in the test suite — non-Gold edit attempts now correctly get a 403.

Fixed Right Now no longer fakes a "Live" status on save failure

Removed the local-optimistic fallback in app/(tabs)/right-now.tsx. A failed save now shows a clear error and leaves the status off — it never again claims the user is live when the backend never received the update.

Fixed College Verification now has a real entry point

The row in app/verification.tsx is now tappable and opens a two-step sheet (.edu email → 6-digit OTP), reusing the existing OtpCodeInput component and wired to the backend's already-built POST /college / POST /college/confirm endpoints. No longer a permanent dead end.

P2 — Fixed

Fixed Group "Media, Links & Docs" now paginates past the first 50 items

app/rooms/media.tsx now tracks a cursor per tab and calls onEndReached to fetch more, matching the pagination the backend (rooms.service.ts) already supported. Older shared media in long-running groups is reachable again.

"Coming Soon" stubs — resolved

Two of the four remaining stubs turned out to be quick real fixes; the other two would have needed features that can't be honestly built in a 1–2 day window (a social graph, live location streaming), so they were removed from the UI entirely rather than left as a tappable dead end.

✓
Mute chat (1:1) — turned out the backend was already fully built (a real Mute model + /safety/users/:id/mute endpoints, already wired into push-notification suppression). Wired the Inbox multi-select bell icon to it — it's a real, working feature now, matching Groups' mute.
—
Friends — removed the sidebar menu item. No social-graph feature exists to back it; leaving a stub there would fail your "no dead buttons" bar.
—
Share Live Location — removed the pill and duration chips from the location sheet. Sending a static pin (already fully working) remains; live streaming needs real backend infra that can't be built honestly in this window.
✓
GIF picker — re-confirmed this was never actually a live stub: its "coming soon" text only renders if EXPO_PUBLIC_KLIPY_API_KEY is unset, and it's set in both frontend/.env and .env.prod. No user will ever see it.
